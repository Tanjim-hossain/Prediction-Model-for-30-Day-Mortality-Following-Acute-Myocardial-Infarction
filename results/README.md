# Results

This folder contains curated machine-readable tables transcribed directly from the executed final notebook outputs.

The values are included so that reviewers can inspect headline results without running the full repeated nested-validation workflow. The authoritative computational record remains `notebooks/01_Full_Analysis_Executed.ipynb`.

Generated runtime outputs from local/Kaggle re-runs should go to `outputs/`, which is ignored by Git. Curated portfolio results in this directory are version controlled.
